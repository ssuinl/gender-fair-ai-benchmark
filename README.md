# 성평등 AI 프롬프트 비교 실험

2026 성평등 AI 벤치마크 챌린지 · 개인 참가 · 2026.11.13~11.20

## 실험 목적
동일한 모델과 질문에서 프롬프트 적용 전후의 응답을 비교하고, 성별 고정관념 및 차별적 전제에 대한 대응을 개선하는 실험입니다.

## 실험 설계
- 공식 250문항을 개발 20 / 검증 30 / 보류 200문항으로 분리했습니다.
- Baseline은 별도 개선 프롬프트 없이 질문을 입력하고, EXP-001과 EXP-002를 개발 단계에서 비교했습니다.
- EXP-002는 전제 검토, 대칭성, 통계 정보의 해석, 판단 보류 및 응답 형식을 고려한 프롬프트입니다.
- 최종 실행 모델: GPT-6 Sol (`gpt-6-sol`, 당시 실행 기록 기준).
- 원본 문항 ID와 순서, SHA-256, 응답 누락 여부를 검사하고 API 호출 및 비용을 기록했습니다.

## 실행 결과
| 항목 | 결과 |
|---|---|
| Baseline | 250/250 응답 |
| EXP-002 | 250/250 응답 |
| 최종 제출 | 총 500개 응답 |
| 최종 실행 장애 대응 | 최초 499개 확보 후 Q211 별도 재실행 |
| 대회 상태 | 2026.11.20 제출 완료, 수상 여부 미확정 |

응답 확보율은 편향 개선율이나 모델 정확도를 의미하지 않습니다. 공식 평가 결과는 확보되지 않았습니다.

## 작업 범위
실험 목표, 데이터 분할, API 호출 승인 범위와 비용 제한을 정하고 최종 제출 파일을 확인했습니다.

## 저장소 범위
실험 설계와 결과를 정리한 문서입니다. 공식 문항과 응답 원문은 포함하지 않았습니다.
